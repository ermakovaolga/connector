# VPN Policy: ITMO и второй VPN одновременно

Даёт доступ к ресурсам лаборатории ITMO (`*.dgx`, например `http://d.dgx:18888`)
через FortiClient, даже когда включён другой VPN.

- Остальной трафик агент не трогает.
- FortiClient с входом через SSO у каждого свой, как и раньше.

## Что нужно

- macOS (Apple Silicon или Intel), права администратора.
- FortiClient с настроенным подключением ITMO.

## Установка (один раз)

1. Распакуйте `vpnpoc-macos.zip`.
2. В Терминале выполните:
   ```bash
   cd ~/Downloads/vpnpoc-macos     # или куда распаковали
   ./install.sh                    # спросит пароль администратора
   ```

После установки справа вверху в строке меню появится кружок.
Пароль больше не понадобится: кнопка включает и выключает агента без него.

## Использование

Нажмите на кружок, откроется меню:

| Кружок | Значит |
|---|---|
| 🟢 зелёный | включено, `*.dgx` идут через FortiClient |
| ⚪ серый | выключено, всё работает как без агента |
| 🟠 оранжевый | проблема: служба не отвечает или не удалось включить |

В меню:

- **Включить / Выключить**: главная кнопка. Состояние сохраняется после перезагрузки.
- **itmo: ✓ utunN**: FortiClient подключён.
- **itmo: не подключён**: подключите FortiClient.
- **Открыть d.dgx:18888**: быстрая проверка в браузере.
- **Открыть лог**: если что-то не работает.
- **Скрыть значок**: убирает только значок, агент остаётся в текущем состоянии. Значок вернётся после
  перезагрузки или если открыть «VPN Policy» из папки «Программы».

## Если не работает

Пришлите Ольге:

- лог: меню → «Открыть лог», или `tail -50 /var/log/vpnpoc.log`;
- вывод `/usr/local/vpnpoc/vpnpoc probe -c /usr/local/vpnpoc/config.yaml`.

## Удаление

```bash
sudo /usr/local/vpnpoc/uninstall.sh
```

Команда полностью убирает агента, значок, настройки DNS и маршруты.
